# 🧱 벽짓고 살아남기 (WallSurvival)

스타크래프트 유즈맵 '벽짓고 살아남기'에서 영감을 받은 싱글 플레이 생존 게임. 파일 하나(`index.html`)로 돌아가며 브라우저에서 열면 바로 실행된다.

## 규칙
- **낮**: 미네랄을 캐서 돈을 벌고 벽·터렛·보급고를 지어 요새를 만든다. 첫 낮 75초, 이후 40초.
- **밤**(50초): 맵 가장자리에서 **킬러**와 졸개들이 나타나 플레이어에게 가는 가장 '싼' 길(빈 칸 + 벽 체력)을 계산해 약한 벽부터 부수고 들어온다.
- 킬러는 밤마다 강해진다. 밤 중에 킬러를 쓰러뜨리면 **격퇴** — 밤이 바로 끝나고 보상이 커진다.
- **10번째 밤**을 버티면 승리, 체력이 0이 되면 패배.

## 조작
| 입력 | 동작 |
|---|---|
| 우클릭 / 좌클릭 | 이동, 미네랄 클릭 시 채굴 |
| WASD | 직접 이동 |
| 1~5 | 벽 / 철벽 / 문 / 터렛 / 보급고 선택 (드래그로 연속 건설) |
| X | 판매 모드 (체력 비례 50% 환불) |
| R | 자동수리 켜기/끄기 (주변 1칸 건물, 돈 소모) |
| N | 낮 건너뛰고 밤 바로 시작 |
| P / Esc | 일시정지 / 선택 취소 |
| 미니맵 클릭 | 그 위치로 이동 |

## 건물·업그레이드
| 건물 | 비용 | 체력 | 특징 |
|---|---|---|---|
| 벽 | 20 | 160 | 기본 벽 |
| 철벽 | 80 | 650 | 강화 벽 |
| 문 | 40 | 260 | 플레이어만 통과 |
| 터렛 | 120 | 220 | 사거리 4.5, 14 피해/0.6초 |
| 보급고 | 150 | 360 | 초당 +2원 |

업그레이드: 벽 강화(벽·철벽·문 체력 +30%/Lv), 터렛 화력(+30%/Lv), 채굴 숙련(+40%/Lv).

## 밸런스
수치는 `index.html` 상단 `CFG` / `TYPES` / `UPGRADES` / `killerStat` / `minionStat`.
- 킬러: 체력 320×1.5^(n−1), 공격 12×1.38^(n−1) / 0.9초
- 졸개: 체력 50×1.38^(n−1), 공격 4×1.32^(n−1), 밤마다 2+2n마리
- 자동 플레이 검증: 3×3 칸에 갇혀 터렛·업그레이드만 사는 단순 봇은 밤 6~7에서 사망 → 철벽·보급고·확장을 쓰는 사람은 10밤 도달 가능한 수준을 목표로 함.
