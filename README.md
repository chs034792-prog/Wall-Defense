# 🧱 벽짓고 살아남기 (WallSurvival)

스타크래프트 유즈맵 '벽짓고 살아남기'에서 영감을 받은 싱글 플레이 생존 게임. 파일 하나(`index.html`)로 돌아가며 브라우저에서 열면 바로 실행된다.

## 규칙
- **낮**: 미네랄을 캐서 돈을 벌고 벽·터렛·보급고를 지어 요새를 만든다. 첫 낮 75초, 이후 40초.
- **밤**(50초): 맵 가장자리에서 **킬러**와 졸개들이 나타나 플레이어에게 가는 가장 '싼' 길(빈 칸 + 벽 체력)을 계산해 약한 벽부터 부수고 들어온다.
- 킬러는 밤마다 강해진다. 밤 중에 킬러를 쓰러뜨리면 **격퇴** — 밤이 바로 끝나고 보상이 커진다.
- 10의 배수 밤에는 **보스 킬러**(체력 ×1.6, 공격 ×1.2)가 나온다.
- **100번째 밤**을 버티면 승리, 체력이 0이 되면 패배. 한 판이 2시간 반 정도 걸린다.
- 매일 새벽 **자동 저장**(브라우저 localStorage) — 시작 화면의 '이어하기'로 계속. 죽거나 새로 시작하면 저장이 지워진다.

## 조작
| 입력 | 동작 |
|---|---|
| 우클릭 / 좌클릭 | 이동, 미네랄 클릭 시 채굴 |
| WASD | 직접 이동 |
| 1~5 | 벽 / 철벽 / 문 / 터렛 / 보급고 선택 (드래그로 연속 건설) |
| X | 판매 모드 (체력 비례 50% 환불) |
| R | 자동수리 켜기/끄기 (주변 1칸 건물, 돈 소모) |
| N | 낮 건너뛰고 밤 바로 시작 |
| F | 2배속 켜기/끄기 |
| P / Esc | 일시정지 / 선택 취소 |
| 미니맵 클릭 | 그 위치로 이동 |

## 건물·업그레이드
| 건물 | 비용 | 체력 | 특징 |
|---|---|---|---|
| 벽 | 20 | 160 | 기본 벽 |
| 철벽 | 80 | 650 | 강화 벽 |
| 문 | 40 | 260 | 플레이어만 통과 |
| 터렛 | 120 | 220 | 사거리 4.5, 14 피해/0.6초 |
| 보급고 | 150 (+20/채) | 360 | 초당 +3원, 지을수록 비싸짐 |

업그레이드: 벽 강화(벽·철벽·문 체력 +30%/Lv, 최대 40), 터렛 화력(+30%/Lv, 최대 40), 갑옷(내 최대 체력 +40%/Lv, 최대 40), 채굴 숙련(+40%/Lv, 최대 15). 비용 = 기본가 × (1+Lv)^1.35.

수입: 기본 초당 1원 × (1 + 0.2 × 지난 밤 수), 채굴, 보급고, 졸개 처치(4+2n), 새벽 보상(60 + 45n, 격퇴 시 60 + 80n).

## 밸런스
수치는 `index.html` 상단 `CFG` / `TYPES` / `UPGRADES` / `killerStat` / `minionStat`.
100밤까지 가야 하므로 지수 성장 대신 다항식 성장. g = 1 + 0.2(n−1)
- 킬러: 체력 320×g², 공격 12×g^1.6 / 0.9초 (밤 10 ≈ 4천, 밤 50 ≈ 3.7만, 밤 100 ≈ 13.8만)
- 졸개: 체력 50×g^1.8, 공격 4×g^1.5, 2 + min(38, 0.8n)마리
- 자동 플레이 검증: 중앙 3×3 요새를 고정 순서로 넓히고 보급고·업그레이드를 사는 단순 봇은 밤 10(첫 보스)~17에서 사망. 100밤 완주 가능 여부는 아직 사람 플레이로 확인하지 않았다.
