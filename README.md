# 🧱 극한 벽짓고 살아남기 (Wall Defense)

스타크래프트2 유즈맵 **'극한 벽짓고 살아남기'**를 참고한 싱글 플레이 생존 디펜스. 파일 하나(`index.html`)로 돌아가며 브라우저에서 열면 바로 실행된다.
참고 영상: https://youtu.be/umqnKiG5-YE (아구 TV, 스타2 벽 짓고 살아남기)

## 규칙
- 난이도 **쉬움 / 보통 / 어려움 / 악몽** 중 선택. 난이도별 최고 기록이 저장된다.
- 둥지에서 좀비가 쉬지 않고 몰려온다. 웨이브는 30초마다, 총 **100웨이브**(처음 60초는 준비 시간).
- 처음엔 **동쪽 둥지**만 열려 있고 기지 입구는 동쪽 두 곳. **30웨이브에 북쪽 둥지, 60웨이브에 남쪽 둥지**가 열리며 새 입구가 생긴다 (악몽은 21·42웨이브).
- 적은 넥서스까지 가는 가장 '싼' 길(거리 + 벽 체력)을 계산해 약한 입구를 노린다. 비행 적은 벽을 넘어오고, 땅굴벌레는 땅속으로 기지 안까지 파고든다.
- **넥서스**가 부서지면 패배. **100웨이브 최종 보스(칼날 여왕 케리건)**를 잡으면 승리.
- 10웨이브마다 고유 패턴 보스, 보스 직전엔 공생충. 5웨이브마다(악몽은 3) 이벤트. 적이 **300마리** 쌓이면 폭주 괴수.
- 프로브가 죽으면 8초 뒤, 영웅은 30초 뒤 넥서스에서 부활. 매 웨이브 시작 시 자동 저장.

## 돈과 보급
- 10초마다 **수급**: (40 + 일꾼×12 + 수정탑×20) × (1 + 0.6 × 광물 시설 Lv) × 난이도 보정.
- 일꾼 최대 10, 수정탑 최대 20(지을수록 +15원, 보급 +8), 광물 시설 5단계, 광물 은행(보유 광물 2% 이자, 최대 3개).
- 가스 정제소(분출구 2곳) 수급마다 가스 +90, 향상된 가스 업그레이드, 광물 400 → 가스 100 교환.
- **보급**: 기본 10 + 수정탑당 8 (최대 170). 유닛마다 보급을 쓴다.

## 콘텐츠
**건물 15종** — 벽, 강화벽, 중장갑 벽(피해 -10), 가시 벽(35% 반사), 포토캐논(3단계는 범위), 수정탑, 보호막 충전소(건물·유닛 수리), 광전사 석상(근접 범위), 가스 정제소, 사이오닉 오벨리스크(폭풍), 공허 포격 포대(같은 적을 계속 쏘면 최대 5배), 정지 수정(감속), 사이오닉 지뢰(길을 안 막는 1회용), 광물 은행, 감지탑(땅굴 탐지·사거리 +1).
캐논·석상·충전소는 3단계, 오벨리스크·공허 포대·정지 수정은 2단계까지 개별 강화 (3단계는 첨단 방어 연구소 필요).

**유닛 17종 + 영웅 2** — 광전사, 사도(경장갑 2.5배), 추적자, 용기병, 파수기(수호 보호막), 고위기사(폭풍) → 집정관, 암흑기사(은폐), 불멸자(중장갑 3배), 거신, 분열기(정화 폭발), 리버, 불사조(대공 3배), 공허 포격기, 폭풍함, 캐리어, 모선(감속 오라). 영웅 **알라라크**(범위 근접·흡혈), **카락스**(건물 수리).
지상 전용 유닛은 비행 적을 못 친다. 같은 유닛 2기를 **조합**하면 ★(공격·체력 2.2배, 보급 1.5배), ★★(4.8배, 보급 2.25배).

**테크 10종** — 게이트웨이, 첨단 방어 연구소, 사이버네틱스 코어, 황혼 의회, 기사단 기록보관소, 암흑 성소, 로보틱스 시설, 로보틱스 지원소, 우주관문, 함대 신호소.

**업그레이드 13종** — 벽 강화, 벽 장갑, 방어 화력, 방어 사거리, 지상 무기, 공중 무기, 보호막, 광물 시설, 향상된 가스, 수리 효율, 폭탄 강화, 시간 증폭 강화, 현상금.

**능력 6종** — 폭탄, 정지장, 시간 증폭, 보호막 과충전, 궤도 폭격, 긴급 귀환.

**적 14종 + 정예** — 저글링, 바퀴(재생), 히드라리스크(원거리), 맹독충(자폭), 감염된 해병, 뮤탈리스크(비행), 울트라리스크(휩쓸기), 감염된 공성전차(장거리 포격), 군단숙주(식충 소환), 무리군주(비행·새끼 벌레), 땅굴벌레(땅속 침투), 공생충, 폭주 괴수. 10웨이브부터 정예(체력 4배, 보상 5배).

**보스 10종** — 가시 촉수 괴물(원거리 가시), 울트라리스크 왕(주변 벽까지 파괴), 오메가리스크(저글링 소환), 감염된 튼튼 로봇(피해 50% 감소), 브루탈리스크(산성 범위), 리바이어던(비행·뮤탈 소환), 감염된 토르(사거리 8, 유닛 우선), 혼종 약탈자(벽 너머 순간이동), 혼종 파괴자(재생 보호막·폭풍), 칼날 여왕 케리건(3단계 패턴, 분노).

**이벤트 10종** — 광란, 철갑, 황금 웨이브, 대군, 비행 습격, 산성비, 보급 지원, 땅굴 습격, 정예 부대, 정전.

## 밸런스
수치는 `index.html` 상단 `DIFF` / `CFG` / `BLD` / `UNITS` / `TECH` / `UPS` / `ABIL` / `ENEMY` / `BOSSES` / `EVENTS`.
- 웨이브 성장 g = 1 + 0.12(w−1). 적 체력 × g^1.8, 공격 × g^1.5. 보스 체력 800 × g^2.3 (최종 ×2.5). 폭풍·영웅은 g^0.6 로 같이 강해진다.
- `tools/balance-bot.js`: index.html 을 연 브라우저 콘솔에 붙여 넣고 `runBot(101, { diff: 'normal' })` → `window._r`.
  입구 이중벽 + 벽 바로 뒤 캐논 + 수급·테크·캐리어 위주로 고정 순서로 사는 단순 봇(오벨리스크·공허 포대·지뢰·정지 수정·영웅 미사용) 결과: **보통 54웨이브, 쉬움 76웨이브**.
  캐논을 벽에서 멀리 두면 보통 6~8웨이브에 무너진다 — 첫 캐논은 벽 바로 뒤에.
- 영상에서 확인한 요소(일꾼 10, 수정탑 20, 수급 단계, 몸빵벽/진짜벽, 수리, 포토캐논 3단계, 보호막 충전소, 폭탄, 시간 증폭, 적 300 누적 강적, 공생충 → 보스, 보스 이름들, 케리건, 거신·캐리어·광전사 석상·알라라크·카락스·집정관 조합, 악몽 난이도)를 바탕으로 했고, 가격·체력 등 세부 수치는 지어낸 값이다.
