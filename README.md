# 🧱 극한 벽짓고 살아남기 (Wall Defense)

스타크래프트2 유즈맵 **'극한 벽짓고 살아남기'**를 참고한 싱글 플레이 생존 디펜스. 파일 하나(`index.html`)로 돌아가며 브라우저에서 열면 바로 실행된다.
참고 영상: https://youtu.be/umqnKiG5-YE (아구 TV, 스타2 벽 짓고 살아남기)

## 규칙
- 맵 오른쪽 끝 **둥지**에서 좀비가 쉬지 않고 몰려온다. 웨이브는 30초마다, 총 **100웨이브**. 처음 60초는 준비 시간.
- 기지로 들어오는 **통로 입구는 위·아래 두 곳**. 좀비는 넥서스까지 가는 가장 '싼' 길(거리 + 벽 체력)을 계산해 약한 입구를 노린다.
- **넥서스**가 부서지면 패배. **100웨이브 최종 보스(칼날 여왕 케리건)**를 잡으면 승리.
- 10웨이브마다 보스(가시 촉수 괴물 → 울트라리스크 왕 → 오메가리스크 → 감염된 튼튼 로봇 → …). 보스 직전 웨이브에 **공생충**이 나온다.
- 적이 **300마리** 쌓이면 폭주 괴수가 나오고 그동안 새 적은 대기한다.
- 프로브(내 일꾼)가 죽으면 8초 뒤 넥서스에서 다시 소환된다.
- 매 웨이브 시작 시 자동 저장(브라우저 localStorage), 시작 화면의 '이어하기'로 계속.

## 돈 (수급)
10초마다 **수급**이 들어온다: (40 + 일꾼×12 + 수정탑×20) × (1 + 0.6 × 광물 시설 Lv).
- 일꾼 최대 10, 수정탑 최대 20(지을수록 +15원), 광물 시설 업그레이드 최대 5단계.
- 가스 정제소(가스 분출구 2곳)는 수급마다 가스 +60.
- 좀비 처치 시 광물, 보스 처치 시 광물·가스 보너스.

## 조작
| 입력 | 동작 |
|---|---|
| 우클릭 / 좌클릭 | 프로브 이동 |
| 1~7 | 벽 / 강화벽 / 포토캐논 / 수정탑 / 보호막 충전소 / 광전사 석상 / 가스 정제소 (드래그로 연속 건설) |
| X / R | 판매(체력 비례 50%) / 자동수리 켜기·끄기 |
| Q | 폭탄 — 마우스 위치 반경 3 큰 피해 (40초) |
| E | 시간 증폭 — 20초간 수급 속도 2배, 방어·유닛 공격 속도 1.5배 (90초) |
| G | 마우스 위치를 전투 유닛 집결지로 |
| 방향키 / 미니맵 클릭 | 화면 이동, Space 로 프로브에게 복귀 (미니맵 우클릭 = 이동 명령) |
| F / P / Esc | 2배속 / 일시정지 / 선택 취소 |

## 건물·유닛·테크
| 건물 | 비용 | 체력 | 특징 |
|---|---|---|---|
| 벽 | 25 | 400 | 몸빵용 |
| 강화벽 | 100 | 1500 | 진짜 벽 |
| 포토캐논 | 150 | 600 | 사거리 6, 18 피해/0.8초 |
| 수정탑 | 100+15n | 300 | 수급 +20 |
| 보호막 충전소 | 125 | 400 | 반경 4 건물 초당 48 수리 |
| 광전사 석상 | 400/100 | 2500 | 반경 1.7 범위 40 피해/0.8초 (게이트웨이) |
| 가스 정제소 | 75 | 500 | 가스 분출구 전용 |

전투 유닛(넥서스에서 생산, 집결지 방어): 용기병 150/50, 거신 300/200(범위), 캐리어 600/400.
테크: 게이트웨이 → 사이버네틱스 코어 → 로보틱스 시설 / 우주관문 → 함대 신호소.
업그레이드: 벽 강화(+40% 체력), 방어 화력(+25%), 유닛 공격(+25% 공격·체력) 각 최대 30, 비용 = 기본가 × (1+Lv)^1.4.

## 밸런스
수치는 `index.html` 상단 `CFG` / `BLD` / `UNITS` / `TECH` / `UPS` / `ENEMY` / `BOSSES`.
- 웨이브 성장 g = 1 + 0.12(w−1). 적 체력 × g^1.8, 공격 × g^1.5. 보스 체력 800 × g^2.3 (최종 ×2.5).
- 웨이브당 좀비 6 + 1.1w, 맹독충(6웨이브부터) w/4, 울트라리스크(20웨이브부터).
- `tools/balance-bot.js`: 브라우저 콘솔에 붙여 넣고 `runBot(101)` → `window._r` 로 결과 확인. 입구 이중벽 + 캐논 14개 + 수급·업그레이드·유닛을 고정 순서로 사는 단순 봇은 캐논을 먼저 갖춘 판에서 64웨이브, 수정탑을 먼저 산 판에서 8웨이브에 패배.
- 영상에서 확인한 요소: 일꾼 10기 제한, 수정탑 20개로 수급 증가, 광물 시설·파일런 단계 업그레이드, 몸빵벽/진짜벽, 수리, 포토캐논, 보호막 충전소, 폭탄, 시간 증폭, 좀비 처치 시 광물, 적 300마리 누적 시 강적, 공생충 → 보스, 보스 이름들, 최종 보스 케리건, 거신·캐리어·광전사 석상. 가격·체력 등 세부 수치는 지어낸 값이다.
